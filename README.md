Proyecto simulación ambulancia.
En este proyecto se pretende crear un carrito que funcione como una versión básica de una ambulancia.
Utilizando el simulador de Tinkercad construiremos un carrito que pueda ser controlado de forma remota, con control de velocidad, giro y una sirena.
